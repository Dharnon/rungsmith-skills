# Check a browser API at the deployment boundary

## Set up the case

For a copy-ID request, identify whether the target is a native component, a hosted demo or an installed module. Look for a documented native action on the installed version.

## Exercise the interaction

Exercise the native action and the selectable-text fallback in the deployed client. A successful clipboard operation in a website preview supplies evidence only for that preview.

## Acceptance and evidence

Record the action owner, client and observed result for each surface.

## Assess an anchored help surface

Identify the trigger, help content, keyboard access and dismissal requirement. Compare the installed component's supported tooltip with an explicit native information panel. Test a narrow host and a touch client. If the web reference needs an unsupported browser anchoring hook, document the remaining positioning difference and the supported way to access the same help.
