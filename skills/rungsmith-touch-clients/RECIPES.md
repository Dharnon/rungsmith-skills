# Keep Apply reachable with the software keyboard open

## Set up the case

On the target touch device, open a filter popup at the smallest supported orientation. Focus its last editable field and enter a value that causes validation feedback.

## Exercise the interaction

Check whether the popup body or the page scrolls to the field. Attempt to reach Apply, dismiss the keyboard and reopen the same popup. Adjust the owning container when its footer is clipped.

## Acceptance and evidence

Record viewport size with keyboard open and whether scrolling from a label accidentally activates a neighboring control.

## Rotate a device with an editor open

Start a fixture edit, display validation feedback and rotate if the deployment supports rotation. Confirm the draft and asset identity survive according to the host contract, the keyboard does not hide the only dismissal path and the body still scrolls. Repeat in the reverse orientation with long translated labels.
