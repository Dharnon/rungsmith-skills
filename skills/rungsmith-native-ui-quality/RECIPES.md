# Review the route from alarm to equipment detail

## Set up the case

Start on a simulated alarm row, open its equipment detail and return to the filtered list. Include two assets with the same display label and one invalid reading.

## Exercise the interaction

At each step identify the source, quality and next available action. If the wrong equipment opens, repair the selection contract before polishing spacing or transition timing.

## Acceptance and evidence

Document the first decision the operator could get wrong, its owning resource and the acceptance replay.

## Read an overview with color removed

Use development fixtures for running, stopped, unavailable and alarmed equipment. Inspect the view in a monochrome capture and then in its deployed theme. Record which distinctions survive through labels, placement or shape. Open each detail and confirm its header and quality indication agree with the overview. Recheck one keyboard route after any layout change.
