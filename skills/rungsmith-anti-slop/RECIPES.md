# Remove one box without losing equipment grouping

## Set up the case

Duplicate the development view. Give adjacent pumps the same current reading and different quality. Hide only the inner reading border in the copy.

## Exercise the interaction

Trace a value to its equipment label, unit and quality cue at normal working distance. If the boundary between pumps is lost, move the grouping cue to the equipment header.

## Acceptance and evidence

Keep the smallest edit that preserves attribution at narrow width and after a quality change.

## A summary row inherits styling from a detail card

Embed the existing child in a compact overview and a standalone detail view. Remove the inner heading only in the overview variant. Test a long name and a failed pressure reading beside a healthy neighbor. Pass when both surfaces still identify their equipment and the reduced variant fits its host without changing the shared default.
