# Stress-test a view

A reproducible defect report with data cases and native test evidence.

## Workflow

1. Map rendered fields and realistic lengths, ranges and missing states.

2. Build isolated test fixtures for long names, empty results, quality loss and multiple instances.

3. Check narrow size, zoom, keyboard and reconnect behavior; record causes and proposed fixes.

## Perspective constraints

Read the actual native view contract and target-version APIs. Keep process state, command permission and interlocks owned by the host. Use supported native properties/events and scoped CSS; web libraries, DOM APIs and React adapters are not executable view definitions. Preserve unrelated resources and local customizations. Do not queue per-frame Gateway scripts to imitate browser-local feedback.

## Evidence and handoff

A reproducible defect report with data cases and native test evidence. Record the resource paths and tested client/state. Distinguish static checks, import and native interaction verification. Mark unsupported or untested behavior explicitly.
