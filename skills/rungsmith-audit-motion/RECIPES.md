# Find a shared transition defect

## Set up the case

Choose the overview, a repeated card and its detail popup. Record one full route and list each style class applied on entry.

## Exercise the interaction

Refresh one simulated reading without navigating. If multiple cards replay their entrance, trace shared class assignment and instance reconstruction separately.

## Acceptance and evidence

File one repair for the shared cause. Include an unaffected view and one second consumer as controls.

## Turn an audit into a small repair queue

Walk overview → alarm detail → history → overview. Record each trigger once on a normal route and once with a delayed reading. Group results by owner. For each repair give a replay, the first visible failure, a second consumer to regression-test and a stop condition. Leave aesthetic preferences without an observable consequence as review notes.
