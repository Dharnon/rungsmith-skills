# Remove an entrance without stranding a popup

## Set up the case

Locate the native close action and any timer or class binding tied to the exit duration. Disable the visual effect in a development copy and leave the normal close route intact.

## Exercise the interaction

Open, dismiss and reopen quickly. If focus or clicks land on an invisible surface, fix the popup lifecycle before removing obsolete CSS.

## Acceptance and evidence

Verify pointer access, keyboard traversal and a second asset after dismissal. Record which cleanup no longer depends on elapsed time.

## Stop a live table from animating every update

Feed a stable dataset, then change one measurement repeatedly without inserting a row. Observe which element re-enters. Inspect class binding, row identity and container reconstruction. Remove the trigger at the narrowest owner. Then insert a genuinely new record and check selection, quality indication and scroll position for existing rows.
