# Turn a density correction into a scoped rule

## Set up the case

Compare the requested historian table edit with the touch picker that shares its theme. Identify the specific row or style resource the reviewer changed.

## Exercise the interaction

Write the proposed rule against its task: comparing timestamps on a workstation. Check whether applying it to the touch picker reduces usable target area.

## Acceptance and evidence

Record the evidence, affected resource family and counterexample. Promote the rule only at the scope the reviewer actually established.

## Retire an obsolete styling convention

Take one existing project rule and inspect two current consumers. If the consuming style was replaced or the reviewer subsequently narrowed its scope, draft a revision that preserves the original rationale only where it still applies. Record one view that should change, one that should stay as designed and the evidence for both.
