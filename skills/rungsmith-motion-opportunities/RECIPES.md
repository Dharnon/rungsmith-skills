# Decide whether a row reveal earns motion

## Set up the case

Compare a persistent selected-row marker with a short reveal of the associated maintenance details. Feed both the same update that reorders the list.

## Exercise the interaction

Ask the reviewer to locate the originally selected asset after refresh. If stable identity already solves the task, drop the motion proposal. If detail provenance remains unclear, keep only the local reveal.

## Acceptance and evidence

Record the operator error the proposal addresses and the equivalent cue available with reduced motion.

## Compare a cue against a stationary alternative

Give the reviewer two versions of an equipment-detail reveal with identical data and layout. One retains a visible selected-row marker; the other adds a local reveal as well. Reorder the list during selection. Record whether the reviewer finds the intended equipment faster or more reliably, and whether a second abnormal row remains noticeable.
