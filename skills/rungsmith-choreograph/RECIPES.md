# Coordinate a detail header and a late-loading trend

## Set up the case

Open a fixture faceplate whose history result can be released independently. Show equipment identity and close affordance with the shell. Reserve the chart area using the host layout.

## Exercise the interaction

Release the history result after the panel settles. Only the chart region should change. Close before release and open a different asset; the previous result must have no visible effect on the new panel.

## Acceptance and evidence

Record three sequences: data already present, data delayed, panel replaced. Identify which element leads in each.

## Switch tabs while history is loading

Keep the equipment header mounted as the Control and History surfaces change. Bind selection to one host-owned tab value. Keep the active tab indicator tied to that value and the chart readiness tied to the history result. These are independent signals. If the trend fails, preserve the selected tab and display the failure in the reserved content area.

Replay History, Control, History before the first result arrives. Track asset and time window for both requests. Accept a result only when its context still matches the visible selection. Watch the control tab during the replay: its command area must remain usable immediately after the switch.

## Diagnose a list that ripples on every refresh

Separate the event that inserts an asset from the event that refreshes its reading. Disable the entrance class temporarily. If the operator still loses their row, inspect sorting, focus and identity before restoring any animation. A stagger on re-sorted alarm rows can conceal which asset changed priority. Keep the priority and identity readable throughout the reorder.

## Coordinate an empty-to-populated maintenance list

Start with a successful empty result, keep the heading and active asset stationary, then release three fixture rows. Add a fourth row during the transition. Observe whether existing rows replay their entrance and whether focus jumps away from the toolbar. Preserve the active filter, scroll owner and identity of the selected record across the update.
