# Port an equipment sheet with a long maintenance note

## Set up the case

List the source behavior in order: open from selected equipment, retain identity, scroll details, dismiss and return to the opener. Compare the native popup and dock against the need to keep working in the parent.

## Exercise the interaction

Build one fixture with a long note and unavailable reading. Switch equipment while loading and check which surface owns scrolling and how dismissal works on keyboard and touch.

## Acceptance and evidence

Hand off the supported native resource and the observable differences that matter to the operator.

## Port a command toolbar with a fixture target

Choose one harmless simulated command from the reference. Map displayed availability, user intent, pending state, authoritative result and failure recovery. Open two native instances with different assets and delay the first result. Confirm the second instance remains independent. Deliver the resource paths, parameter directions and behavior gaps with the verified interaction sequence.
