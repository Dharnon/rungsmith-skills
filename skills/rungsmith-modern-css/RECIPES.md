# Fit one child into two panel widths

## Set up the case

Embed the same view in two hosts of different widths on one page. Begin with a readable stacked layout. Apply a project-owned class to the intended query container.

## Exercise the interaction

Resize one host with the page viewport fixed. If both instances change together, inspect whether the rule measures viewport width or the wrong ancestor.

## Acceptance and evidence

Keep the fallback and record the smallest width where the last unit label and command remain accessible.

## Fit an engineering unit beside a long value

Use a fixture with a negative signed value, a longer translated unit and a quality marker. Resize the embedded host without resizing the page. Verify the unit remains associated with the number and the quality marker stays visible. Compare the baseline and enhanced layouts and record the width at which each one changes.
