# Triage a slow popup with three timestamps

## Set up the case

Observe trigger activation, shell appearance and first valid sample in a launched session. Repeat with the same asset already cached.

## Exercise the interaction

If the shell appears late even with fixture data, inspect launch and construction cost. If the shell is prompt and the bound value is late, follow the binding. If both are ready behind a fade, inspect motion.

## Acceptance and evidence

Hand off the first delayed milestone, resource and replay steps to the matching workflow.

## Route a report that “the button does nothing”

Use a fixture button and a traceable harmless host intent. Observe activation, receipt and visible feedback independently. No activation by keyboard points toward keyboard-focus; two recipients point toward perspective-interactions; one received intent with no pending cue points toward notifications. Include the one observation that eliminated the closest alternative.
