# Select by identity after filtering

## Set up the case

Build a local options fixture containing two identical labels and distinct values. Configure the installed native selector in Designer using its documented option shape.

## Exercise the interaction

Select the second value, filter it out and restore the options in reversed order. Inspect the host binding before and after each change.

## Acceptance and evidence

Choose the implementation whose identity and empty-selection behavior satisfy the host contract. Record any adapter needed.

## Pick a control for a small fixed choice

Compare a native selector with the project's existing segmented equipment view. Give both three modes, one unavailable option and a host-driven change. Test narrow width, keyboard selection and the emitted ID. Record the first unsupported requirement for each candidate and which project resource would need to own the workaround.
