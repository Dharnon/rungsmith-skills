# Catch one click reaching two handlers

## Set up the case

Place two copies of one equipment view on the same page. Give them different instance identities even when they represent the same simulated asset.

## Exercise the interaction

Record the activator, message type, configured scope and each recipient. Count handlers that act separately from handlers that receive. Narrow scope or filter by instance according to the host contract.

## Acceptance and evidence

Repeat with keyboard activation. A single visible popup can conceal duplicate actions targeting the same ID.

## Prevent an echo between host and child

Give a fixture host a selected value and record child outputs. Change the host value programmatically, then make the equivalent user selection. Observe whether reconciliation emits the same public action twice. Preserve the existing consumer contract, document which changes count as intents and confirm a second instance remains independent.
