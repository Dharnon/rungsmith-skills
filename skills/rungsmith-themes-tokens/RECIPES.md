# Check focus and alarm priority together

## Set up the case

Choose one project Style Class used by both normal and alarmed equipment. Focus the alarmed control by keyboard and inspect it under each supported theme.

## Exercise the interaction

If the focus outline disappears over alarm styling, inspect the winning declarations and restore an independent focus cue at project scope. Look for consumers before editing a shared theme.

## Acceptance and evidence

Verify normal, alarmed, focused and alarmed-plus-focused states at the same client size.

## Migrate one duplicated color without broad visual churn

Pick two consumers that use the same literal value for clearly different purposes. Introduce or reuse the semantic role for only one purpose. Toggle the project's supported themes and inspect both consumers, focused and unfocused. Verify the unrelated consumer retains its prior appearance and the migrated class still inherits the correct theme value.
